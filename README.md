# 🥁 Drum Key Combinations

Use the following key combinations to create great-sounding drum patterns.

## 🎵 Key Mapping

| Key | Drum Sound |
|-----|------------|
| W | Crash Cymbal |
| A | Floor Tom |
| S | Snare |
| D | Mid Tom |
| J | High Tom |
| K | Kick |
| L | Low Kick / Bass |
